# 撞墙了么

**你追你的，墙就在那儿。**

一款纯前端 H5 追逐诱导游戏。操控试验场里的小机器人「阿零」，通过走位、闸门和信标，把机械追逐者带到墙边，再横向脱身。

进阶版重做了四章 **20 关**：有限距离冲刺、三种不同的追逐策略、踏板闸门，以及共用两格电量的闪避与信标。保留首页、继续挑战、选关、说明、设置、暂停、快速重试、星级、最终通关和自由重玩。无后端、登录或联网排行榜。

## 本地试玩

Node.js **24.x**，按锁文件安装：

```sh
npm ci
npm run dev
```

打开 [本地试玩](http://127.0.0.1:5173/)。首页与 Phaser 引擎分包，进入关卡时按需加载。

- **电脑**：WASD / 方向键移动，空格闪避，E 放信标，Escape / P 暂停。
- **手机**：左手四向键，右手闪避 / 信标。支持同时按方向和技能、松手及触控取消。
- 闪避走两格，没有无敌；信标留在原地 2.8 秒。每次各用一格电，每 3 秒补一格，上限两格。
- 走入字母踏板切换对应门。预警 / 冲刺期间及关门格被占用时，切换排队；以地图与 HUD 的当前门状态为准。
- 橙色正式预警锁定攻击方向与路径，不会追着玩家转弯。敌人冲刺只有 3—5 格，需要主动选择撞击位置。
- 每关有可立即开始的简短准备提示；重试跳过提示。切后台自动暂停，返回手动继续。
- 过关一星，时间达标和闪避次数达标各得一星；超目标仍可获胜。

新版使用 `wallbait.save.v2`，与旧版成绩分开。旧键原文保留，仅迁移音效与动态效果设置；旧通关不解锁重新设计的关卡。浏览器存储异常时仍能游玩，但关闭或刷新后可能无法保留进度。

## 验证与证据

```sh
npm run check
npx playwright install chromium webkit
npm run test:e2e
npm run test:static
```

| 命令                       | 内容                                                              |
| -------------------------- | ----------------------------------------------------------------- |
| `npm run check`            | ESLint、Prettier、Vitest、严格类型检查、生产构建                  |
| `npm test`                 | 规则、迁移、20 关固定回放、140 轮简单策略及事件报告核验           |
| `npm run test:e2e`         | 桌面/手机尺寸 Chromium、手机尺寸 WebKit、完整流程、触控、连续闯关 |
| `npm run test:static`      | 生产包 `/wallbait/` 子路径资源、通关与恢复                        |
| `npm run replays:generate` | 规则/关卡调整后显式重新搜索合法操作解                             |
| `npm run build`            | 构建到 `dist/`                                                    |

20/20 关具备正常出生到胜利的纯命令回放。七种固定简单策略中，第 11—20 关均未被通关；第 1、3、5、7 关保留教学与过渡的宽容解。自动回放只证明可解，不能当作人类难度或手感成绩。实际执行情况、交互试玩与剩余限制见 [验收记录](docs/testing/README.md)。

中后期已补第 8、10、13、15、20 关的[代理交互抽样](docs/testing/followup-2026-11-04.md)，五关均通过正常操作获胜，含失败与重试记录；使用频繁暂停和临时选关夹具，不代表真人实时或连续 20 关成绩。真机、扩大真人测试及低端设备性能继续列为[后续事项](docs/remaining-work.md)。真机目前不可连接；手机尺寸 Chromium/WebKit 与 CDP 多指测试属于浏览器模拟，不能冒充 iPhone Safari / Android Chrome 真机验收。

## 项目结构

- `src/core/`：纯 TypeScript 整数网格、固定步、状态机、机关、碰撞与关卡。
- `src/game/`：Phaser 绘制、插值、程序音效；动画不决定碰撞。
- `src/input/`：键盘与多点 Pointer Events，输出玩家命令。
- `src/ui/`：流程、HUD、双技能操作区与原创矢量主题。
- `src/storage/`：版本化存档、成绩隔离、校验与异常回退。
- `tests/`：关键规则、固定回放、反套路、浏览器与子路径验收。
- `docs/`：玩法、架构、逐关方案、开发记录和实际截图。
