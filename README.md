# 撞墙了么

**你追你的，墙就在那儿。**

一款纯前端 H5 追逐诱导游戏。操控试验场里的小机器人「阿零」，通过走位、闸门和信标，把机械追逐者带到墙边，再横向脱身。

进阶版重做了四章 **20 关**：有限距离冲刺、三种不同的追逐策略、踏板闸门，以及共用两格电量的闪避与信标。技能版新增脉冲与磁推工具选择，以及连冲、侧切、干扰三种强化敌人能力；保留第 11/18 关残骸布局、四类精彩操作和第 7/11/18 关记忆芯片，局内仍只有两个技能按钮。保留首页、继续挑战、选关、说明、设置、暂停、快速重试、星级、最终通关和自由重玩。无后端、登录或联网排行榜。

## 本地试玩

Node.js **24.x**，按锁文件安装：

```sh
npm ci
npm run dev
```

打开 [本地试玩](http://127.0.0.1:5173/)。首页与 Phaser 引擎分包，进入关卡时按需加载。

- **电脑**：WASD / 方向键移动，空格使用所选工具，E 放信标，Escape / P 暂停。
- **手机**：左手四向键，右手工具 / 信标。方向首次轻点即走一格，按住连续走，支持滑动换向、滑出停止和多指技能；连点仍受 120ms 移动间隔限制。
- 准备页保留信标，工具可选闪避，第6关解锁脉冲、第9关解锁磁推；结算与暂停可换装重开。脉冲暂停两格内无遮挡敌人0.6秒；磁推在攻击间隙把面前残骸向前推一格，落点有预览。
- 闪避走两格，没有无敌；信标沿朝向投出最多两格，遇障碍停在前方，贴墙落在脚下；准星显示落点，持续 2.2 秒。每次各用一格电，每 3 秒补一格，上限两格。
- 敌人撞毁后留下单格残骸，其他攻击结束且无人占格后成为障碍；空心叉框待生效，实心叉框阻挡移动，也能让下一只敌人撞毁。第 8 关“残骸接力”教学此规则。
- 走入字母踏板切换对应门。预警 / 冲刺期间及关门格被占用时，切换排队；以地图与 HUD 的当前门状态为准。
- 编号旁“+”表示强化敌人：冲锋者冲空后完整重新预警追击一次，截击者先预告侧切落点，侦察者预告固定十字干扰场、场内暂停回充。
- 橙色正式预警锁定攻击方向与路径，不会追着玩家转弯。敌人冲刺只有 3—5 格，需要主动选择撞击位置。
- 金色方芯经过即可拾取，闪避途中也能收集；带着芯片通关才保存，部分关卡将带回芯片作为战术星目标。失败可重试，选关页查看三段记忆和累计精彩操作。
- 借尸筑墙、一标双骗、脚下留电与擦肩而过按实际操作判定，通关后留档；局内短反馈不覆盖危险提示。
- 每关有可立即开始的简短准备提示；重试跳过提示。切后台自动暂停，返回手动继续。
- 准备页的开始/返回入口固定保留，详细说明可展开；地图首次绘制完成后才能开局，加载失败提供重新加载入口。
- 工具按钮提示前方阻挡、近敌无遮挡、等待攻击结束或磁推落点限制；Tab 聚焦方向/技能按钮后可用 Enter 操作，Ctrl / Command 等组合键不触发暂停。
- 敌人与预警终点显示相同编号和类型符号，蓄力倒计时显示在敌头上方；危险提示优先冲刺，再按即将发动的顺序排列。
- 失败后可查看冻结现场：标出致命敌人、碰撞格和攻击路线，再返回结算或直接重试。
- 过关、时间与当关战术目标各一星；技能使用不扣星，超目标仍可获胜。历史星级单独标注、重玩后记新成绩；解锁与收藏保留。

技能规则与验收范围见[技能规格](docs/design/skills.md)。新版使用 `wallbait.save.v2`，与旧版成绩分开。旧键原文保留，仅迁移音效与动态效果设置；旧通关不解锁重新设计的关卡。浏览器存储异常时仍能游玩，但关闭或刷新后可能无法保留进度。

## 验证与证据

```sh
npm run check
npx playwright install chromium webkit
npm run test:e2e
npm run test:static
```

| 命令                       | 内容                                                              |
| -------------------------- | ----------------------------------------------------------------- |
| `npm run check`            | ESLint、Prettier、Vitest、严格类型检查、生产构建                  |
| `npm test`                 | 规则、迁移、20关主线、3条芯片、27条搭配、20条战术及140轮策略核验  |
| `npm run test:e2e`         | 桌面/手机尺寸 Chromium、手机尺寸 WebKit、完整流程、触控、连续闯关 |
| `npm run test:static`      | 生产包 `/wallbait/` 子路径资源、通关与恢复                        |
| `npm run replays:generate` | 规则/关卡调整后显式重新搜索合法操作解                             |
| `npm run build`            | 构建到 `dist/`                                                    |

20 关主线、三条芯片支线、27条替代搭配、20条战术目标与七种固定简单策略随规则变更重新验证，最新状态见[技能版记录](docs/records/2026-11-04-skills.md)。自动回放只证明可解，不能当作人类难度或手感成绩。实际执行情况、交互试玩与剩余限制见 [验收记录](docs/testing/README.md)。

加载保护、准备页布局与工具反馈的本轮问题清单及验证见[交互优化记录](docs/records/2026-11-04-optimization.md)。

机制更新前，中后期已补第 8、10、13、15、20 关的[代理交互抽样](docs/testing/followup-2026-11-04.md)，五关均通过正常操作获胜，含失败与重试记录；使用频繁暂停和临时选关夹具，不代表真人实时或连续 20 关成绩。真机、扩大真人测试及低端设备性能继续列为[后续事项](docs/remaining-work.md)。真机目前不可连接；手机尺寸 Chromium/WebKit 与 CDP 多指测试属于浏览器模拟，不能冒充 iPhone Safari / Android Chrome 真机验收。

## 项目结构

- `src/core/`：纯 TypeScript 整数网格、固定步、状态机、机关、碰撞与关卡。
- `src/game/`：Phaser 绘制、插值、程序音效；动画不决定碰撞。
- `src/input/`：键盘与多点 Pointer Events，输出玩家命令。
- `src/ui/`：流程、HUD、双技能操作区与原创矢量主题。
- `src/storage/`：版本化存档、成绩隔离、校验与异常回退。
- `tests/`：关键规则、固定回放、反套路、浏览器与子路径验收。
- `docs/`：玩法、架构、逐关方案、开发记录和实际截图。
