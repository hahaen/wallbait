# 界面

`App`负责首页、选关、准备、对局、暂停、结算与失败现场。以用户提供的参考图为准，全局奶油底、深棕粗描边、浅绿棋盘、圆润蛇、红苹果和红色圆角工具按钮；首页、说明、结算与对局共用手绘透明角色图集，避免画风割裂。

正文遵循渐进展示：首页只留标题、宣传语和入口，每关准备一句提示，工具使用短标签。对局常驻剩余蛇数、时间、电量；移除常驻教学和星级目标，门/信标/收藏只报短状态。规则、目标、档案和结算详细成绩按需展开。未开放信标隐藏，触屏隐藏桌面按键说明。准备与结果采用内容滚动、底部操作固定的布局，保留安全区。手机摇杆直径144–164px、方向热区52px，主工具至少108×104px，信标至少108×48px，双手控件互不重叠。可用状态只保留图标和名称，冷却或阻挡时再显示短提示。

`utilityFeedback`共用核心拒绝条件，提示阻挡、无脉冲目标、磁推限制和干扰停充；提示不代替规则执行。原生dialog限制焦点，打开时聚焦标题，关闭返回原焦点，避免自动给次要展开项画出大焦点框。

胜负时立即清空输入，禁用控件并保存胜利，保留1200ms现场后弹结算。后台不展示，回来重新留足停留时间；换关/销毁清理定时器，返回结果不重复保存。失败现场展示碰撞格和真实路线，规则冻结，可返回结果或重试。浏览器验证和真机边界见[豆豆与摇杆记录](../../records/2026-11-04-bean-thumb.md)。
