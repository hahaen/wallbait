# 界面

`App` 管理首页、四章选关、对局，以及原生 dialog 暂停/说明/设置/结算。dialog 提供焦点约束，关闭返回原焦点。只在胜利结算边界记成绩，下一关和重试均创建新状态。

准备页用独立滚动内容和固定操作区，开始/返回按钮不随长说明滚出视口。初始地图绘制完成前禁用开始，快捷键也不能恢复；加载失败保持冻结并可重新加载页面。`utilityFeedback` 根据核心校验显示闪避阻挡、脉冲目标、磁推拒绝原因与干扰停充，核心仍负责最终执行。

主题为废弃试验场中的小机器人阿零。首页保留游戏名称、宣传语和机械追逐插画；对局使用较小关名、计时、剩余敌人、两格共享电量与恢复倒计时。门显示当前开闭及待执行状态，信标显示寿命，敌人状态栏显示蓄力方向、冲刺或恢复提示。

地图占剩余高度，左手方向与右手两个技能位于地图外。CSS 使用 `100dvh`、安全区和窄屏规则；具体尺寸与触控结果以[验收文档](../../testing/README.md)为准。技能未启用、充电中、工具短锁和信标在场分别显示状态；是否接受操作仍由核心规则决定。

首页有新版成绩时显示继续挑战，同时保留从第一关重玩。选关显示各章、名称、星级与锁定状态。对局和结算显示时间与战术目标，胜利记录用时、闪避、信标；失败显示碰撞原因和当前关卡提示。最后一关展示终局反馈，已解锁关可自由重玩。

旧版通关数量在首页显示为保留记录，不用于新版解锁或星级。设置保留静音与减少动态效果；存储不可用时提示本次进度仍在、刷新可能丢失，不阻止游玩。

视觉以深蓝试验场、青绿色主角和橙红紫敌人为主，门与踏板使用字母配对，危险格使用橙色箭头。系统中文字体、首页矢量插画、游戏程序绘图，无外部字体或图片网络依赖。

危险提示先展示正在冲刺的敌人，再按蓄力剩余时间和编号排列；倒计时在地图敌头上显示，避免每 0.1 秒重复朗读状态栏。失败结算提供“查看失败现场”，现场显示致命敌人、按接触类型给出的建议和标记图例，可返回结算（含 Escape / P）或直接重试；查看时隐藏无效的移动技能区。

保留工具、信标两个技能按钮，工具随准备页装备选择；信标准备态显示“前投 ≤2格”，HUD 增加残骸已阻挡/待生效计数。第 5、7、8 关提示和玩法说明解释投掷方向、落点准星和残骸状态。

新增地图外固定反馈行，芯片携带与最近称号不覆盖危险栏；准备、结算解释可选收集，选关页试验档案显示三枚记忆与四种操作。失败提示本局芯片未带出，较差重玩不清空已归档收藏。

技能版准备页提供信标固定槽及工具三选一，第6/9关依次开放脉冲/磁推。仅准备态且未推进对局时允许选择；暂停或结算可换装重开。空格与原工具按钮统一使用所选工具，准备按钮有 aria-pressed、描述与触控间距。星级改为通关/时间/战术，历史星级明确标注；旧解锁不倒退。四章有场地区域短文，干扰状态在电量与机关行提示。
