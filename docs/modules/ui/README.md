# 界面

`App`负责首页、准备、对局、暂停、结算与失败现场。以用户提供的参考图为准，全局奶油底、深棕粗描边、浅绿棋盘、圆润蛇、红苹果和圆角道具控件；首页、说明、结算与对局共用手绘透明角色图集，避免画风割裂。

首页把剩余高度分配到标题上方和操作区下方。手机视口跨过 740 CSS 像素的紧凑布局断点时，插画尺寸会调整，主内容仍在可用区域居中。浏览器回归覆盖截图对应的近似尺寸、断点两侧和更短的视口，检查标题留白和两个操作按钮的首屏可见性。微信真机待复测。

点击开始后显示短加载提示，地图就绪后自动开局。局内常驻剩余蛇数或换波倒计时、时间与护盾。右下提示用与地图一致的图标显示当前掉落，并标明是踩上生效还是拾取。诱饵按钮只在携带诱饵时可用，手机可与摇杆同时操作。门、诱饵与冰冻各显示简短状态。

原生 dialog 限制焦点，打开时聚焦标题，关闭返回原焦点。加载中可以回首页，加载失败保留重载入口。设置开关在当前控件上更新值并保留焦点。P/Escape 可暂停或继续实战，也可从失败现场返回结算。

被抓时立即清空输入、禁用控件并保存新纪录，保留1200ms现场后弹结算。后台不展示，回来重新留足停留时间；离场或销毁时清理定时器，返回结果不重复保存。失败现场展示碰撞格和真实路线，规则冻结，可返回结果或重试。浏览器验证和真机边界见[豆豆与摇杆记录](../../records/2026-11-04-bean-thumb.md)。
