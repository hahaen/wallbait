# 界面

`App` 管理首页、四章选关、对局，以及原生 dialog 暂停/说明/设置/结算。dialog 提供焦点约束，关闭返回原焦点。只在结算边界记成绩，下一关和重试均创建新状态。

首页保留大标题、宣传语和追逐插画；对局仅小关名、计时、剩余蛇、技能冷却。地图占剩余高度，操作区独立置于地图外。CSS 使用 `100dvh`、安全区、最小 44px 方向键与手机窄屏规则。

首页主按钮在有进度时变为继续挑战，同时可从第一关重玩。星级规则与每关目标显示在对局和结算，选关显示已得星级与锁定状态。最后一关展示通关反馈，已解锁关可自由重玩。

视觉：奶油 `#f8f1df`、墨色 `#3d3528`、蛇绿 `#b6cf70`、苹果红 `#ef674c`，系统中文字体。首页采用矢量插画，游戏使用程序绘图，无外部字体或图片网络依赖。
