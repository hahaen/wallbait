# 存档

`wallbait.save.v3` 保存个人无尽纪录、工具偏好、静音和减少动态效果。个人纪录先比完成波数，再比撞毁数。被抓时如果刷新纪录，立即写入；查看失败现场或返回结算只更新界面。

读档优先使用有效 v3。首次进入时，可从 `wallbait.save.v2`（`foundry-v2`）继承有效无尽纪录、装备与设置。更早的 v1 只继承静音和减少动态效果。旧关卡成绩与收藏保留在原始存档键。读取不会写入，后续保存只写 v3。

各键分别处理损坏数据及读取异常。无效工具回退为闪避，纪录中的波数、撞毁数需为合理范围内的整数。写入失败时本次会话仍使用内存里的设置和纪录，设置或结算会提示。重新载入从已保存的纪录开始，当前对局重新开局。
