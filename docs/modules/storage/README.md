# 存档

当前键为 `wallbait.save.v2`，版本 2，关卡集标识 `foundry-v2`。保存连续关卡解锁、每关最佳用时/最少闪避/最少信标/最佳星级、静音和减少动态效果。四项最佳独立累计，可以来自不同次通关；较差重玩不会覆盖成绩。

## 旧版迁移

旧键 `wallbait.save.v1` 只读保留，原始内容不覆盖、不删除。首次进入新版时只继承静音和减少动态效果设置；旧关卡的成绩、星级与解锁不会进入重做后的关卡。新版从第 1 关开始，`legacyCompleted` 仅用于提示旧版已完成多少关，不参与新版成绩和解锁计算。

读档不隐式写入。第一次保存设置或通关时写入新版键；已有有效新版存档时，新版设置优先。旧键与新键分别容错，某一键损坏或不可读不会阻断另一键。原始旧版记录仍可由原版本读取。

## 校验与边界

读取仅接纳已知关卡编号的有限范围整数字段，解锁由连续通关成绩重建。未知版本、不同关卡集、非法 JSON、无效字段返回默认值或丢弃无效记录；若旧版有效，则仍可继承旧版设置。访问 localStorage 属性、getItem、setItem 均在异常边界内。

写入失败继续保留内存进度，并在结算/设置提示刷新可能丢失。没有云同步；刷新恢复已完成关卡与设置，不恢复正在进行中的一局。测试见 `tests/storage.test.ts` 与浏览器流程。
