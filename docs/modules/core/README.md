# 核心规则开发文档

规划对应源码：`src/core/`。本目录用于后续开发说明，建立文档目录不代表功能已实现。

整体规则、架构与开发计划的位置见[文档导航](../../README.md)。

后续在本目录记录：

- 状态、配置、命令、事件及统一逻辑入口。
- 苹果移动、蛇状态机、闪避与冷却。
- 固定时间步、逐格碰撞、同一步冲突和结算顺序。
- 关键规则测试与边界用例，链接到对应测试文件或[验收记录](../../testing/README.md)。

核心保持纯 TypeScript，不依赖 Phaser、DOM 或存储；坐标使用整数格，时间使用毫秒。
具体接口随功能实现补充，尚未落地的设计标注为计划。
