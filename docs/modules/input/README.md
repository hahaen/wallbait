# 输入

`Controls` 每局创建一组可 Abort 的监听器，销毁时解除。键盘和触控统一进入按住方向 Map。键盘最近的两个垂直方向合成斜向，最后按下且仍按住的键决定主轴；手机摇杆保留拖动角度。

手机使用 Pointer Events、pointer capture 和独立 pointerId，方向与诱饵可以多点同时按下。`pointerup`、`pointercancel`、`lostpointercapture` 释放对应指针；取消和异常丢失捕获会取消该指针尚未采样的技能，正常快速点击仍保留一次操作。多个手指按同一按钮时，只有全部释放才移除按下外观。

WASD / 方向键移动，Space 原地放诱饵，Escape / P 暂停。诱饵意图在下一次固定步采样后清除，键盘自动重复不会连续触发。失焦与 `visibilitychange` 在 App 边界自动暂停，继续前清空输入并释放捕获。

输入不写玩家坐标、敌人阶段或胜负；统一输出 `Command`。浏览器多点触控、取消及连续重开的实际结果见[验收文档](../../testing/README.md)。

方向首次点按立即移动，松手与换向不会清除剩余步进间隔。采样前已松开的快速方向点按保留一次意图；取消、失焦和清理会丢弃未采样意图。手机摇杆以圆心为基准，18%半径为死区，拖出外圈保持角度，旋钮位移限制为45%半径。回中心取消未采样方向；取消、暂停、窗口尺寸变化和销毁重置旋钮与捕获。四个方向也可直接点按，技能指针独立，支持双指移动加工具。`joystickIntent` 计算移动向量和工具朝向。

空格与诱饵按钮复用原主工具的一次性意图，规则层检查是否已拾取诱饵。历史输入夹具仍测试闪避方向快照和信标键边界。

方向和诱饵按钮获得焦点后可用 Enter 操作；按住方向按钮的 Enter 连续移动，松开停止，快速点按保留一次意图。Ctrl / Command / Alt 组合键在暂停判断前排除，保留浏览器系统快捷键。
