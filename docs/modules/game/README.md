# 游戏与渲染

`createGame` 在关卡开始时惰性加载 Phaser，首页不等待完整游戏引擎。场景每帧最多补算五个 20ms 步；暂停、重开和结束不积压补帧。

`Arena` 缓存静态网格和墙，动态绘制苹果、蛇身、蛇头、锁向箭头通道、蓄力进度与撞墙/闪避粒子。普通位移插值，冲刺使用更短插值；碰撞从不读取视觉坐标。减少动态效果设置及系统 reduced-motion 均关闭位置插值与震屏。

页面切换销毁旧 Phaser 实例；惰性加载完成时核对当前状态引用，防止快速切换后复活旧对局。暂停重置累积时间与镜头震动。

`Sound` 使用 Web Audio 程序合成短音效，仅用户手势创建/恢复 AudioContext。静音及音频异常不影响规则。每个短音结束断开节点，卸载时关闭 Context。
