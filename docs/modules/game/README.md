# 游戏与渲染

`createGame`在Phaser场景就绪、首次地图绘制完成后通知UI，规则由20ms固定步推进。暂停或终局不推进规则；终局仍绘制以收尾撞击粒子，再由UI延迟显示结算。失败终止帧关闭插值，对齐真实碰撞格。

`Arena`绘制浅绿棋盘、圆润石墙、红苹果、三色蛇、字母机关、信标、收藏和空/实残骸。没有蓄力进度、倒计时、停车锁定标签、预告路线或路线终点编号。多蛇通过编号与类型纹样辅助识别，单条普通蛇省略标签；失败默认展示轻微挤压、小跳与表情变化；真实攻击快照只在主动进入“查看失败现场”时绘制。

画布按设备像素比最高3倍渲染，用摄像机缩放保持原416×480逻辑画面；文字纹理同步分辨率。平滑位置、镜头和粒子均不参与碰撞，减少动态效果关闭插值与震屏。素材由本地透明PNG图集、SVG容器与程序图形组成，无远程依赖。`characters.ts`定义图集帧与切片，三色蛇头、开心表情、豆豆和苹果在场景预加载后共用纹理；逐帧仅更新位置、表情和大小。大脑袋、小身体，豆豆由大到小渐缩，没有连接杆。图集失败时保持规则冻结并显示重载入口。素材及最终提示词见[角色资源](../../design/bean-mascots.md)。
