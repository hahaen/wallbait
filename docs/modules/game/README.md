# 游戏与渲染

`createGame` 在关卡开始时惰性加载 Phaser，首页不等待完整游戏引擎。场景每帧最多补算五个 20ms 步；暂停、重开和结束不积压补帧。

`Arena` 缓存静态网格和墙，动态绘制青绿色机器人阿零、三类机械敌人与履带、配对踏板和门、信标寿命、锁向箭头通道、蓄力进度及撞墙/闪避粒子。预警格来自核心 `warningPath`，不用另一套碰撞或预测逻辑。门按当前开闭绘制，待执行请求显示提示，不提前改变地形外观。

普通位移插值，冲刺使用较短插值；碰撞从不读取视觉坐标。阿零的白色方向标表示规则朝向，便于观察截击者的预测轴线。角色形状与纹理辅助颜色识别：冲锋者圆角箭头，截击者方形闪电，侦察者菱形传感器。

减少动态效果设置及系统 reduced-motion 都会关闭位置插值与震屏。信标脉冲使用对局规则时间，暂停后不继续消耗寿命；暂停帧也不推进场景动画。

页面切换销毁旧 Phaser 实例；惰性加载完成时核对当前状态引用，防止快速切换后复活旧对局。暂停重置累积时间与镜头震动。

`Sound` 使用 Web Audio 程序合成短音效，仅用户手势创建/恢复 AudioContext。静音和音频异常不影响规则。每个短音结束断开节点，卸载时关闭 Context。完整运行与子路径验收结果见[验收文档](../../testing/README.md)。

敌头与预警终点显示相同编号和类型符号，敌头显示蓄力剩余时间。失败终止帧关闭插值，对齐规则格后标出致命碰撞格及路线快照；查看现场时规则与画面均保持冻结。

残骸以叉框绘制，空心缺角表示待生效、实心表示障碍，置于门图层之上以免门格内的残骸被覆盖。未放信标且有电时，以核心 `beaconLanding` 绘制落点准星；实际信标寿命使用 2200ms 规则常量。

金色方形带引脚芯片与圆形信标、叉框残骸区分，置于危险通道下方。芯片/精彩操作有短程序音效，仍支持静音和减少动态效果。

技能版增加强化“+”、二段标记、侧切预告、十字干扰条纹、暂停倒计时与磁推落点；橙色正式攻击通道置于场地效果之上。四章地面标线和墙面高光有差别，仍无外部资源依赖。脉冲、磁推与能力预告使用独立程序音效。
