# 游戏与渲染

`createGame`在Phaser场景就绪、首次地图绘制完成后通知UI，规则由20ms固定步推进。暂停或终局不推进规则；终局仍绘制以收尾撞击粒子，再由UI延迟显示结算。失败终止帧关闭插值，对齐真实碰撞格。

`Arena`绘制浅绿棋盘、圆润石墙、红苹果、嫩绿/奶黄/浅紫豆豆蛇、字母机关、信标、收藏和空/实残骸。没有蓄力进度、倒计时、停车锁定标签、预告路线或路线终点编号。三类蛇分别使用嫩绿、奶黄、浅紫的同一套手绘造型，各自的头、身体与开心表情配色一致；类型靠配色和头顶造型识别，强化用小金星标识；移除虫身上所有编号、类型、强化加号、暂停和命中文字；失败默认展示轻微挤压、小跳与表情变化；真实攻击快照只在主动进入“查看失败现场”时绘制。

画布按设备像素比最高3倍渲染，用摄像机缩放保持原416×480逻辑画面；文字纹理同步分辨率。平滑位置、镜头和粒子均不参与碰撞，减少动态效果关闭插值与震屏。素材由本地透明PNG图集、SVG容器与程序图形组成，无远程依赖。`characters.ts`定义图集帧与切片，三色蛇头、开心表情、豆豆和苹果在场景预加载后共用纹理；逐帧仅更新位置、表情和大小。大脑袋、小身体，豆豆由大到小渐缩，没有连接杆。图集失败时保持规则冻结并显示重载入口。素材及最终提示词见[角色资源](../../design/bean-mascots.md)。

无尽地图在开局时将静态地形绘制为一张纹理。苹果按实际步时连续插值，镜头跟随同一位置并限制在地图范围内。换波只替换蛇的显示对象，画布、地图和镜头保持连续；屏外存活蛇在边缘显示同色方位标记。

`Minimap` 将静态地形绘制在固定画层，叠加当前视野、苹果、蛇、闸门和实心残骸。苹果红点、视野框与主画面同步，角色接近小地图的遮挡范围时缩略图逐渐变淡。

无尽波间小地图用细框和粗框显示两个候选进场区。粗框随规则层的选择更新，波次开始后收起。

`dropEffects.ts` 绘制无尽道具的生效反馈。护盾用双层金边与高光围住苹果，破盾时短暂散开金色碎片并留下断裂轮廓。冰冻时蛇身保持可辨，蛇头四周出现带切面的冰晶。放出的诱饵呈紫色果糖，贴地的波纹标出其所在位置。开启减少动态效果时，道具用静态图形表达状态。
