# 后续验收

当前为三色软萌豆豆、无字角色标识与手机摇杆版，最新结果见[本轮记录](records/2026-11-05-pastel-beans.md)。用户明确要求不再操作或测试真机，当前只使用浏览器验证。旧机械主题下的[交互抽样](testing/followup-2026-11-04.md)仅作历史，不作为新版手感证据。

## 已有证据

- 136项规则、输入、存档、回放与策略测试；20关主线、三条收藏路线、27种工具搭配和20条战术星均可通过正常命令完成。
- 此前版本的小米14实体Chrome实际第一关通关、移动+闪避多点触控、触控取消、暂停冻结和结束现场停留通过，页面脚本错误为0。
- 本轮最终浏览器回归和发布子路径结果统一记录在[本轮记录](records/2026-11-04-bean-thumb.md)。

## 保留的边界

| 项目                         | 当前状态                       | 后续方式                             |
| ---------------------------- | ------------------------------ | ------------------------------------ |
| 实体手机（含小米、iPhone）   | 用户要求停止真机操作与测试     | 仅在用户以后明确重新授权时再做       |
| 真机完整二十关及主观手感     | 未验收；当前仅用浏览器验证     | 保留历史小米抽样，不继续真机测试     |
| 低端设备性能、发热与音效听感 | 未作实体低端机或主观音质评测   | 实体设备项目暂停，当前只做浏览器检查 |
| 更广泛真人难度               | 自动可解与固定策略不能代替真人 | 邀请不同熟练度玩家，按反馈调整       |
