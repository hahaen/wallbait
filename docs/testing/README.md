# 测试与验收记录

测试方案和验收结果保存在本目录；可执行测试代码仍放在仓库根目录的 `tests/`。
总体通过标准随开发计划维护；文档位置见[文档导航](../README.md)。

文件名使用 `YYYY-MM-DD-主题.md`。每份记录写明：

- 验证对象：功能范围、版本或提交，以及对应开发记录。
- 验证环境：浏览器、设备、系统与必要配置。
- 复现步骤：初始状态、操作和预期结果。
- 实际结果：通过、失败或未执行；截图等证据使用相对链接。
- 遗留问题：影响范围、复现条件与后续处理。

自动检查记录实际执行的命令和结果。真机测试须在实际设备执行后才能标记通过；
构建和类型检查不能替代玩法、手感与触控验收。
