## 现状诊断与改变

旧版固定回放平均 2.942 秒，13/20 关不足 3 秒，全部最多一次闪避；最终关 3.54 秒。第 2、4、6 关仅朝一个方向移动两格即可胜利。原因是 9/10 格长冲刺在 11×13 内场常天然够到外墙，三类敌人主要只换速度参数，多敌人沿同一距离场汇合，地形与冷却很少形成后续决策。

实际旧版浏览器试玩：第 1 关等预警后只向右移动一次，2.8 秒、零闪避获胜。

新版缩短为 3/4/5 格冲刺；截击者预测朝向前两格，侦察者避开明显撞墙路径但对信标冒进；加入走位切门及两技能共享电量。第 2 关就需重新设局，门关需选择通路，侦察者要求主动布点。没有增加血量或强制等待。
