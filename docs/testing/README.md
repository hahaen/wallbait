# 验收记录

日期：2026-11-04。环境：macOS，Node.js 24.9.0 / npm 11.6.0。以下均为实际执行结果；未执行项单独列出。

## 核心与可解性

`npm test`：**59 项通过**。

- 按住移动、松手停止、四向/墙与障碍阻挡。
- 两格闪避、当前/最后朝向、冷却、首格阻挡不耗技能、无无敌。
- 三类蛇的预警锁向、冲刺不转弯、冲空恢复。
- 高速逐格检测、相遇、换位穿越、蛇身无伤害、蛇之间不相互淘汰。
- 多蛇部分淘汰不结束、全蛇淘汰胜利、同刻命中优先判负、结算事件只一次。
- 暂停冻结时间/冷却/阶段、重新初始化、星级及存储异常。
- 20 关地图合法性与出生反应距离；静止不操作不会获胜。
- **20 / 20 关固定操作回放获胜**。每关从 `createState` 正常出生开始，仅发送方向/闪避命令，不写入胜负或修改坐标。

回放及各关用时见[关卡设计](../levels.md)和[命令文件](../../tests/fixtures/solutions.json)。束搜索仅用于显式寻找解，正常测试直接重放文件，验证真实规则可通关。
