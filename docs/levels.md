# 20 关设计与通关证据

关卡数据唯一来源：[levels.ts](../src/core/levels.ts)。固定 13 × 15 格，外围封闭；内部实心墙以格坐标配置。全部出生点互不重叠、可达，所有可通行区域连通。追踪不撞墙淘汰，静止不操作不能自动获胜。

回放来源：[solutions.json](../tests/fixtures/solutions.json)。每段输入持续 120ms，包含四向或停止，以及仅在该段首个 20ms 触发的闪避。执行器只调用正常 `createState` / `step`，不修改坐标、蛇状态或胜负。

四章依次为「学会借力」「墙有妙用」「一心两用」「最后的苹果」。回放是可解性证据，不是人类首玩时间或最优解证明；星级时间给初学者留有余量。普通移动也能避开冲刺，闪避提供快速脱离和多蛇脱困手段，不强制每关必须消耗技能。

## 复验

```sh
npm test
# 仅在关卡或规则修改后需要重新寻找解时运行：
npm run replays:generate
```

默认测试直接执行已保存回放，生成器不参与普通验收。修改关卡后不能仅重新生成文件：必须重新评审新规则、执行回放、更新本表并验收受影响的浏览器体验。
