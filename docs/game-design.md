# 玩法设计：苹果与蛇

**撞墙了么** · **你追你的，墙就在那儿。**

操控红苹果，把三类蛇引向石墙、关闭的门或实心残骸，再横向脱身。纯前端单人H5，只有单图无尽挑战，每波一至三条蛇。用户指定的奶油底、粗描边、绿蛇红苹果画风取代机械试验场主题；参考图中的蓄力横幅和预告箭头不采用。

## 追逐与直冲

- 55×61 整数格地图，规则固定步20ms。苹果沿输入角度组合直步和斜步，直步140ms，斜步按距离延长到200ms。首次按下立即走，松手停止发起新步，画面沿每步路线插值。
- 蛇没有蓄力状态、读条、停车锁定提示或提前展示的攻击路线。目标同行/列、五格内、视线畅通且满足短暂观察条件时，直接进入直冲。观察期间继续正常追踪，不是另一段停车蓄力。
- 冲出后保持方向和距离，不因玩家或信标改向。各类蛇的速度与距离见下表。出生后留出观察和走位时间。
- 追踪时绕墙；直冲撞墙、关门或实心残骸才淘汰，冲空后恢复再追。蛇头碰苹果即失败，蛇身无伤害，活蛇之间不碰撞。
- 移动、闪避、冲刺均逐格检查，不能穿墙、穿蛇头或交换位置。同一步先处理玩家，再统一处理蛇；命中优先判负，清空当波后进入波间倒计时。

侦察蛇对真人会拒绝撞障碍的直冲，信标能骗它冒进。信标存在时三类都直接追信标。三类通过配色和头顶造型区分，强化蛇使用小金星标识，虫身不再叠编号或类型文字。出生蛇身向后铺开，仅作表现，不能越过墙、门或角色。

强化蛇从第 5 波逐步出现：冲锋蛇冲空后调整300ms，再次对齐可直接追击；截击蛇侧切前预告400ms；侦察蛇预告600ms后留下2400ms十字干扰场，范围内暂停回充。后两者的能力落点提示用于说明额外技能，不是冲刺蓄力或锁定提示；能力执行后仍需满足直接冲刺的观察条件。

## 两个操作与共享电量

两格电，每3000ms恢复一格。闪避/脉冲/磁推三选一，固定信标从第一波可用。局内两个主动按钮分别对应所选工具与信标。

- 闪避：立即前进两格，耗一电，无无敌；首格被挡不耗电，途中被挡停住。
- 信标：朝前投最多两格，遇障碍停在前一格，贴墙落脚下；持续2200ms，耗一电。不能重放仍在场的信标，已发动的冲刺不改向。
- 脉冲：暂停两格内无遮挡的蛇600ms；无目标不耗电，原攻击方向和剩余步时保留。
- 磁推：在无蛇直冲时推前方实心残骸一格；不可推到障碍、角色、信标或机关关键格。

三个工具与信标各耗一电，工具短锁240ms。同一步双技能先工具再信标，一电时工具成功就不放信标，工具无效则仍可放。共享回充进度、暂停和触控取消按原边界处理；详见[技能规格](design/skills.md)。

## 门与残骸

踩进字母踏板切换同字母门，站住或同组相邻踏板之间移动不反复触发。直冲期间冻结地形，切门请求待结束后执行；角色占门时不关门，可再次踩入取消待执行请求。

撞毁在最后蛇头格留一格残骸。空心叉框待生效、仍可走；所有直冲结束且格内无人后变实心，阻挡角色、视线、投掷与冲刺，可诱撞下一条蛇。新残骸覆盖信标时移除信标，不挤压角色。重开清空本局地形。

## 界面与结束节奏

全局使用奶油底、深棕描边、浅绿棋盘、石墙、圆润蛇和红苹果，首页、说明、准备、暂停、结算与失败现场使用同一套视觉。原创SVG和程序绘图，高清画布最高3倍像素密度，无外部图片/字体依赖。

首页显示标题、宣传语、开始按钮和个人纪录。准备页用短标签选择装备，详细规则可展开。对局常驻剩余敌人或下波倒计时、时间和电量，门与信标仅显示短状态。危险文字只描述已经发生的直冲或能力。桌面有一行按键提示，触屏隐藏。

规则结束立即冻结、清空输入、禁用方向与技能；此时保存新纪录。地图保留1200ms，撞击粒子可收尾但规则不再推进，再显示结算。切后台取消展示定时器，回前台重新留足1200ms；销毁或离场清理旧定时器。

结算显示完成波数与撞毁蛇数。查看失败现场和更换装备按需展开，重试、再来一局和返回首页固定在内容滚动区外。

电脑用WASD/方向键移动，组合垂直方向可斜走，空格用工具，E放信标，P/Escape暂停。手机用全向摇杆与技能圆按钮，支持多点触控、滑动换向和取消释放。100dvh、安全区、窄屏和横屏布局，减少动态效果保留完整反馈。

## 无尽挑战

- 从首页点「开始游戏」进入「回环石园」的装备准备页。55×61格手工场地，全程不换图。镜头跟随苹果，在外墙处停止滚动，保持13×15格的视野；场边小箭头只表示已经进场的屏外敌人位置。
- 左上角小地图显示全场地形、闸门、残骸和存活的蛇。红点是苹果，方框是当前视野，角色靠近遮挡区时全览会变淡。
- 清空当波后有2400ms空档，顶部剩余敌人数量切换成下波倒计时，暂停时冻结。波间仍可走位、使用工具和回电。小地图标出两个可达进场区，粗框表示当前选择。原地等候会保留默认区域，靠近另一处会切换。下一波在所选区域找可达、安全的格子进场。每波1–3条蛇，出生距苹果至少6格，并有至少900ms的初始反应时间。后续波次逐步引入夹击、侦察蛇与强化蛇。
- 苹果位置、电量、信标与闸门状态连续保留。第N波留下的残骸通常能用到第N+2波结束；新波到来时移除更旧的残骸。会封死区域的残骸直接碎掉，磁推不堵死通路，关门请求等通路恢复再生效。
- 被抓结算，先比较完成波数，再比较撞毁数；同刻被抓与清空仍判负。纪录在当前浏览器单独保存。重试复用本局的随机种子；出生点也受苹果位置与地形影响。再来一局使用新种子。
