# 玩法设计：试验场进阶版

**撞墙了么** · **你追你的，墙就在那儿。**

小机器人阿零被困在废弃试验场。通过走位、诱导、闪避和信标，让三类机械追逐者撞上墙或关闭的闸门。四章 20 关，每关一至三名敌人；纯前端单人 H5，不增加后端、账号、支付或联网玩法。

## 移动、碰撞与公平性

- 地图为 13 × 15 格，包含外围墙；规则坐标始终为整数。四向移动每 120ms 一格，按住移动、松手停止，多方向采用最后按下且仍按住的方向。
- 玩家接触敌人头部即失败；履带仅作表现，不伤人。敌人之间不碰撞，也不会互相淘汰。
- 敌人追踪时绕开静态墙和当前关闭的门。只有冲刺撞到这些障碍才被淘汰；所有敌人淘汰后获胜。冲空会进入恢复，再继续追踪。
- 正式橙色预警锁定方向与冲刺距离，之后不再追随玩家或信标改变方向。危险通道只标出实际可经过的格子，并在第一堵障碍前结束。
- 玩家闪避与敌人高速冲刺都逐格处理；闪避不能穿墙、穿敌人或交换头部位置。同一步先处理玩家路径，再处理所有敌人；敌人命中玩家优先判负，随后才检查全部淘汰。结束后冻结，结算事件只发一次。
- 普通移动第一步在收到方向的规则步立即执行；之后每步至少相隔 120ms。松手或换向不清除步进间隔，空闲时倒计时自然归零，快速连点不能加速。
- 固定步为 20ms。暂停冻结对局时间、敌人阶段、回充和信标寿命；失焦或切后台释放输入并暂停，返回后手动继续。画面插值不改变逻辑碰撞顺序。

## 两格电、两种主动操作

最多储存两格电。电量未满时每 3000ms 恢复一格，逐格补充；再次消耗不会清空已有的回充进度。

| 操作 | 收益                                                              | 代价与边界                                                                     |
| ---- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 闪避 | 沿当前输入或最后朝向立即走两格，快速离开预警通道                  | 消耗一格电，240ms 短锁防止连续触发；没有无敌。首格被挡不耗电，途中被挡停在墙前 |
| 信标 | 留在当前位置 2800ms，吸引所有尚未正式锁向的敌人；侦察者会因此冒进 | 消耗一格电；场上已有信标时不能重放。需要在敌人来得及对齐、又能撞墙的位置放置   |

信标从第 5 关启用。信标不阻挡角色，也不会因一名敌人接触而消失；已经锁向的攻击不受新信标或信标到期影响。同一步收到两种技能时先闪避，再在落点放信标；只剩一格电时仅执行闪避。单独放信标与普通移动同时发生时，先放置再移动。

资源取舍来自“为诱导留一格电，还是把电花在立即脱险”。普通走位始终可用，不要求靠技能次数或强制等待拖长关卡。

## 踏板闸门

同字母踏板与门配对。玩家从这组踏板外走入其中一个踏板时翻转开关；站住或在同组相邻踏板之间移动不会反复切换。闪避逐格经过踏板同样触发。

门打开时允许通过并建立视线，关闭时阻挡移动与视线，也能淘汰冲刺中的敌人。任何敌人处于正式预警或冲刺期间，所有切换请求等待执行，保持已展示的攻击路径不变。关门格被玩家或存活敌人占用时也等待，避免夹伤。HUD 显示当前“开/闭”及“待开/待关”；再次踩入可取消尚未执行的切换。应按当前门状态规划路线。

关闭的门可以把信标留在门格内；该信标不会产生穿门追踪路径。无敌人攻击且无角色挡门时，待执行请求才生效。

## 三类追逐者

| 类型   | 识别与目标                                                                           | 追踪每格 | 观察对齐 | 正式预警 | 冲刺每格 / 距离 | 恢复   |
| ------ | ------------------------------------------------------------------------------------ | -------- | -------- | -------- | --------------- | ------ |
| 冲锋者 | 橙色圆角机体、箭头纹；追玩家实际位置或信标                                           | 300ms    | 120ms    | 760ms    | 40ms / 4 格     | 800ms  |
| 截击者 | 红色方形机体、闪电纹；追玩家朝向前两格的预测位置，遇障碍截短；有信标时直接追信标     | 260ms    | 100ms    | 700ms    | 20ms / 3 格     | 1000ms |
| 侦察者 | 紫色菱形机体、圆形传感器；对真人保持至少两格路径距离，靠得太近时退让；对信标正常接近 | 360ms    | 240ms    | 900ms    | 40ms / 5 格     | 600ms  |

三类都需目标同行或同列、五格内且视线畅通才开始观察对齐。侦察者还会检查整段冲刺：对真人时，若五格内会撞障碍便拒绝蓄力；信标可绕过这项判断，因此要主动近墙布点。截击者预测的是朝向，不要求玩家一直移动；阿零身旁的白色方向标帮助判断预测轴线。所有预测、退让和重新站位都发生在正式预警前。

关卡可覆盖基础参数和初始恢复时间。数据及名称、设计意图、主要决策、失败原因、星级目标统一来自 [levels.ts](../src/core/levels.ts)，布局与获胜回放见[关卡设计](levels.md)。

## 四章教学与挑战

1. **唤醒试验场（1—5）**：基本借墙、有限冲刺、闪避、截击预测、踏板和信标逐步出现。
2. **改变追逐路线（6—10）**：闸门与内墙、转角、双敌目标以及共享电量组合。
3. **分配注意力（11—15）**：双门选择、三敌压力、不同诱导条件与交叉预警。
4. **最后的试验（16—20）**：连续改变通路、分批诱导和资源安排；最终关用三间相连试验室串联三类敌人。

教学关允许简单解。中后期设计目标是多次独立设局与资源决策；是否达到目标以命令回放、简单策略专项记录和实际试玩分别验证，不以关卡数量或敌人数代替难度证据。

## 完整流程与存档

保留首页、继续挑战、四章选关、说明、设置、暂停、重试、下一关、星级、最终通关与自由重玩。对局优先显示地图、剩余敌人、电量与回充、信标寿命和门状态。危险提示先列正在冲刺者，再按蓄力剩余时间和编号排序；敌人与预警终点显示编号及类型符号，敌头上方显示蓄力倒计时，颜色不是唯一识别方式。

失败时记录致命敌人、接触类型、碰撞格和路线快照。可从结算进入冻结现场：红圈与叉标出碰撞格，金色框标出冲刺锁向时的完整通道或追踪接触来路；现场不推进规则，也不开放移动与技能。返回结算或重试，重试重新创建整局状态。

通关一星，时间达标一星，闪避次数达标一星；无强制倒计时，信标次数不单独限制星级。每关最佳用时、最少闪避、最少信标和最高星级独立保存。继续挑战进入首个未完成关，全部完成后进入第 20 关；从第一关开始不会清空进度。

新版存档使用 `wallbait.save.v2`，并绑定 `foundry-v2` 关卡集。旧 `wallbait.save.v1` 原文保留且不覆盖，只继承静音和减少动态效果设置，显示旧版通关数量；旧成绩不解锁新版或参与新版评分。损坏或不可用存储回退到可游玩的内存状态，并提示保存失败。

## 操作与视觉

手机左手四向键，右手闪避与信标，右上暂停；支持多点触控、松手和取消。电脑 WASD / 方向键移动，空格闪避，E 放信标，Escape / P 暂停。

深蓝试验场、青绿色阿零、橙红紫三类机械敌人；墙、门、踏板与危险通道以形状、字母、轮廓和纹理辅助颜色识别。首页与结算使用同主题矢量插画，对局用程序绘图，不依赖外部图片或字体。音效可静音，用户首次操作后解锁；减少动态效果关闭位置插值与震屏。实际验收状态见[验收文档](testing/README.md)。
