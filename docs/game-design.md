# 首版玩法设计

## 已确定的项目身份

- 名称：**撞墙了么**。
- 宣传语：**你追你的，墙就在那儿。**
- GitHub：`hahaen/wallbait`。
- 核心体验：操控苹果，把追逐自己的蛇引到墙边，利用冲刺不能转弯的时间差反杀。

以下规则用于指导首个可玩原型，属于待验证的实施方案；视觉概念图不是最终界面。

## 首版范围

一张封闭矩形地图、一条追逐蛇、一个短距离闪避技能。
完成移动、追踪、预警、冲刺、恢复、碰撞、暂停、胜负和重新开始。
不增加普通苹果诱饵、吃食变长、地图障碍、多条蛇、角色性格、商城、联网或排行榜。

## 对局和胜负

1. 苹果与蛇在固定、互不重叠的位置生成，蛇身体初始长度固定。
2. 蛇平时追踪苹果，满足蓄力条件后预警。
3. 蓄力结束锁定方向，沿直线冲刺，冲刺中不能转弯。
4. 蛇头撞到墙，玩家胜利；蛇头碰到苹果，玩家失败。
5. 对局结束冻结规则，显示结果与重新开始按钮。

为保留“引诱冲刺”的体验，普通追踪阶段遇到墙会重新选路或停下，避免蛇无故自撞。
首版不设蛇身伤害、不设饥饿或限时失败，蛇身体只负责表现；后续若增加必须重新评估难度。
同一步胜负冲突的暂定规则见架构文档，首次实现时用测试固定。

## 蛇的状态机

| 阶段              | 行为                                     | 玩家能看到的信号                   |
| ----------------- | ---------------------------------------- | ---------------------------------- |
| 追踪 `tracking`   | 按四向网格追踪苹果，速度低于苹果         | 普通移动                           |
| 蓄力 `charging`   | 停止移动，准备冲刺                       | 强对比方向箭头、危险通道和状态提示 |
| 冲刺 `dashing`    | 快速直线前进，不能转弯                   | 明显的位移和轨迹反馈               |
| 恢复 `recovering` | 冲刺完成且未碰撞时短暂恢复，然后继续追踪 | 疲惫表情或减弱的视觉效果           |

建议在苹果进入同一行或列且处于感知距离内时触发蓄力。
预警方向从蓄力开始固定，蓄力结束后仍沿此方向冲刺，使玩家看到的信息保持可信。
冲刺有距离上限；达到上限且没有撞墙或吃到苹果时进入恢复。
这些触发条件属于原型默认方案，是否容易设局需要可玩测试验证。

## 苹果移动与闪避

- 四向移动，按住持续移动、松开停止；同时按住时采用最后按下且仍按住的方向，不允许斜走。
- 普通移动不能越墙，移动至边界停住。
- 闪避沿当前移动方向，静止时沿最后朝向；初始朝向随出生配置给定。
- 闪避逐格检查，不穿墙；若第一格不可移动，不消耗冷却。
- 闪避不提供无敌时间，路径遇到蛇头仍会失败，避免靠穿头获胜。
- 技能成功发动后开始冷却；HUD 显示就绪或剩余时间。

## 试调参数

下表只是原型起点，尚未写入运行代码。首次可玩验收后再确定。
可通行格不含外围墙；出生点使用整数格，蛇头与苹果须留出反应距离。

| 参数         | 建议初值           | 验证目的                 |
| ------------ | ------------------ | ------------------------ |
| 可通行地图   | 14 × 18 格         | 手机竖屏下能看清危险方向 |
| 逻辑时间步   | 50ms               | 规则与帧率解耦           |
| 苹果移动间隔 | 150ms / 格         | 按住可控、松手停得住     |
| 蛇追踪间隔   | 250ms / 格         | 玩家有绕行和设局空间     |
| 蓄力感知距离 | 同行/同列 6 格以内 | 给玩家主动引诱的机会     |
| 蓄力时长     | 750ms              | 足够读懂预警，但仍需判断 |
| 冲刺间隔     | 50ms / 格          | 与追踪明显区分           |
| 冲刺最大距离 | 8 格               | 可以撞墙，也可能冲空     |
| 恢复时长     | 700ms              | 给失手后的再次布局留时间 |
| 闪避距离     | 2 格               | 帮助离开危险通道         |
| 闪避冷却     | 2500ms             | 防止连续无脑闪避         |

若普通移动即可轻易避开每次冲刺，先调整触发距离、地图空间和节奏，
通过实际操作验证闪避是否有价值，不提前增加新技能。

## 操作与暂停

| 操作      | 手机                   | 电脑                  |
| --------- | ---------------------- | --------------------- |
| 移动      | 左下四向按钮，按住移动 | WASD / 方向键         |
| 闪避      | 右下闪避按钮，显示冷却 | 空格                  |
| 暂停/继续 | 右上暂停按钮与覆盖面板 | Escape / P 与界面按钮 |
| 重新开始  | 结果面板按钮           | 可先通过鼠标点击      |

切后台、窗口失焦时自动暂停并释放所有按住状态；返回后由玩家主动继续。
暂停时蛇行为、移动、技能冷却和对局计时一起冻结。

## 视觉目标

参考 `design/mobile-concept-v1.png` 的奶油底色、绿蛇、红苹果和清晰预警。
正式游戏减少标题占用，地图优先；按钮位于地图之外，适应手机安全区。
危险提示使用箭头和纹理共同表达，不能仅靠颜色区分。
首版先用程序绘图实现，不以完成整套美术作为试玩前提。
