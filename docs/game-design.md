# 玩法设计：试验场进阶版

**撞墙了么** · **你追你的，墙就在那儿。**

小机器人阿零被困在废弃试验场。通过走位、诱导、闪避和信标，让三类机械追逐者撞上墙、关闭的闸门或已生效残骸。四章 20 关，每关一至三名敌人；纯前端单人 H5，不增加后端、账号、支付或联网玩法。

## 移动、碰撞与公平性

- 地图为 13 × 15 格，包含外围墙；规则坐标始终为整数。四向移动每 120ms 一格，按住移动、松手停止，多方向采用最后按下且仍按住的方向。
- 玩家接触敌人头部即失败；履带仅作表现，不伤人。存活敌人之间不碰撞；撞毁后留下的实心残骸按障碍处理。
- 敌人追踪时绕开静态墙、当前关闭的门和实心残骸。只有冲刺撞到静态墙、关闭门或已生效残骸才被淘汰；所有敌人淘汰后获胜。冲空会进入恢复，再继续追踪。
- 正式橙色预警锁定方向与冲刺距离，之后不再追随玩家或信标改变方向。危险通道只标出实际可经过的格子，并在第一堵障碍前结束。
- 玩家闪避与敌人高速冲刺都逐格处理；闪避不能穿墙、穿敌人或交换头部位置。同一步先处理玩家路径，再处理所有敌人；敌人命中玩家优先判负，随后才检查全部淘汰。结束后冻结，结算事件只发一次。
- 普通移动第一步在收到方向的规则步立即执行；之后每步至少相隔 120ms。松手或换向不清除步进间隔，空闲时倒计时自然归零，快速连点不能加速。
- 固定步为 20ms。暂停冻结对局时间、敌人阶段、回充和信标寿命；失焦或切后台释放输入并暂停，返回后手动继续。画面插值不改变逻辑碰撞顺序。

## 两格电、自选工具与固定信标

最多储存两格电。电量未满时每 3000ms 恢复一格，逐格补充；再次消耗不会清空已有的回充进度。

| 操作             | 收益                                                                          | 代价与边界                                                                                                                                                       |
| ---------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 闪避（默认工具） | 沿当前输入或最后朝向立即走两格，快速离开预警通道                              | 消耗一格电，240ms 短锁防止连续触发；没有无敌。首格被挡不耗电，途中被挡停在墙前                                                                                   |
| 信标（固定槽）   | 沿朝向投出最多两格，持续 2200ms，吸引所有尚未正式锁向的敌人；侦察者会因此冒进 | 消耗一格电；场上已有信标时不能重放。遇墙、关闭门或实心残骸停在前一格，紧贴障碍则落在脚下；飞越敌头不造成伤害，不能穿障碍。需要在来得及对齐、又能撞障碍的位置布点 |

第6关起可选择脉冲工具，第9关起可选择磁推工具，与闪避三选一，固定信标保留。脉冲暂停曼哈顿两格内、至少一条直角路径无遮挡的敌人600ms，之后原攻击按原锁向继续；无目标不耗电。磁推把面前实心残骸向前推一格，只在无正式预警/冲刺时生效；落点预览共用核心校验，不可推到墙、角色、其他残骸、信标、未收芯片或机关关键格。各耗一格电并共享240ms短锁；脉冲没有无敌。准备时选工具，暂停/结算可更换并重开，局内仍两个按钮。详见[技能规格](design/skills.md)。

信标从第 5 关启用。信标不阻挡角色，也不会因一名敌人接触而消失；后续被生效残骸覆盖时移除；已经锁向的攻击不受新信标或信标到期影响。同一步收到两种技能时先所选工具，再从工具执行后的位置沿朝向投掷信标；只剩一格电时，工具成功消耗后不放信标，无效工具不耗电，仍可投信标。单独放信标与普通移动同时发生时，先按朝向投掷再移动。

资源取舍来自“为诱导留一格电，还是把电花在立即脱险”。普通走位始终可用，不要求靠技能次数或强制等待拖长关卡。

## 踏板闸门

同字母踏板与门配对。玩家从这组踏板外走入其中一个踏板时翻转开关；站住或在同组相邻踏板之间移动不会反复切换。闪避逐格经过踏板同样触发。

门打开时允许通过并建立视线，关闭时阻挡移动与视线，也能淘汰冲刺中的敌人。任何敌人处于正式预警或冲刺期间，所有切换请求等待执行，保持已展示的攻击路径不变。关门格被玩家或存活敌人占用时也等待，避免夹伤。HUD 显示当前“开/闭”及“待开/待关”；再次踩入可取消尚未执行的切换。应按当前门状态规划路线。

关闭的门可以把信标留在门格内；该信标不会产生穿门追踪路径。无敌人攻击且无角色挡门时，待执行请求才生效。

## 残骸挡路与错峰夹击

每名追逐者撞毁时，在最后所在的可通行头部格留下一格残骸；不是撞击的墙格，也不包含整条履带。同格只保留一块残骸。空心、有缺口的叉框表示待生效，仍允许通过；所有存活敌人的正式预警/冲刺都结束，且残骸格没有玩家或存活敌人时，变为实心叉框并永久阻挡本局移动、视线、追踪、投掷和冲刺。冲刺撞残骸同样淘汰，并留下下一块残骸。

残骸和门共用攻击期间的地形冻结规则，不能中途截断已经展示的攻击路线。新残骸覆盖信标时移除该信标，不挤压角色；暂停不推进生效，重开清空。残骸可能堵住通路，诱撞前要选择位置和击杀顺序。

第 8 关“残骸接力”教学先借短墙、再借残骸诱撞。第 11、13、15、17、18 关调整启动延迟，第 15 关第二名截击者蓄力为 920ms，与另一名的 700ms 错开；不缩短基础预警。需要在躲开当前攻击时安排下一次撤离，实际重叠时长随操作变化，见逐关回放。

## 击杀布局、精彩操作与芯片支线

第 11、18 关采用中央 T 口与右侧备用通路。把第一只引向中央短墙，会在岔口留下残骸：可借它再诱撞，也会堵住原来的中央出口。玩家可以先取左侧芯片，再安排撞毁；也可先解决敌人，经右侧绕路。没有规定唯一击杀顺序，仍以全敌淘汰获胜。

精彩操作每局每类记录一次：

| 称号     | 条件                                                                              |
| -------- | --------------------------------------------------------------------------------- |
| 借尸筑墙 | 一名敌人冲刺撞上实心残骸                                                          |
| 一标双骗 | 两名敌人正式锁定同一枚信标后分别撞毁，信标到期不清除已锁定归属                    |
| 脚下留电 | 零闪避通关                                                                        |
| 擦肩而过 | 蓄力最后 160ms 内从已展示的危险通道离开，并安全避过该次冲刺；返回通道取消该次资格 |

局内地图外显示最近一次称号 3 秒，暂停冻结反馈时间，危险提示独立保留。通关结算展示本局称号，选关页试验档案累计通关获得的称号；失败不增加永久记录，不影响星级和数值。

第 7、11、18 关各放一枚金色方形记忆芯片，作为可选绕路目标。普通移动和闪避逐格经过即可拾取，信标、敌人不代取，碰撞失败格不收集。收集后仍可能失败，只有通关才保存；重开清空本局携带，已归档收藏不倒退。芯片不阻挡移动、不改变追踪目标、不影响电量与普通胜负；第7/11/18关以带回芯片作为战术星目标。残骸可能挡住取芯片路线，需提前选择位置；失败可重试。

三枚芯片解锁三段阿零的试验场记忆，在选关页阅读。没有新技能按钮、战斗属性、额外敌人类型、联网收藏或账号。

## 三类追逐者

| 类型   | 识别与目标                                                                           | 追踪每格 | 观察对齐 | 正式预警 | 冲刺每格 / 距离 | 恢复   |
| ------ | ------------------------------------------------------------------------------------ | -------- | -------- | -------- | --------------- | ------ |
| 冲锋者 | 橙色圆角机体、箭头纹；追玩家实际位置或信标                                           | 300ms    | 120ms    | 760ms    | 40ms / 4 格     | 800ms  |
| 截击者 | 红色方形机体、闪电纹；追玩家朝向前两格的预测位置，遇障碍截短；有信标时直接追信标     | 260ms    | 100ms    | 700ms    | 20ms / 3 格     | 1000ms |
| 侦察者 | 紫色菱形机体、圆形传感器；对真人保持至少两格路径距离，靠得太近时退让；对信标正常接近 | 360ms    | 240ms    | 900ms    | 40ms / 5 格     | 600ms  |

三类都需目标同行或同列、五格内且视线畅通才开始观察对齐。侦察者还会检查整段冲刺：对真人时，若五格内会撞障碍便拒绝蓄力；信标可绕过这项判断，因此要主动近墙布点。截击者预测的是朝向，不要求玩家一直移动；阿零身旁的白色方向标帮助判断预测轴线。所有预测、退让和重新站位都发生在正式预警前。

关卡可覆盖基础参数和初始恢复时间。数据及名称、设计意图、主要决策、失败原因、星级目标统一来自 [levels.ts](../src/core/levels.ts)，布局与获胜回放见[关卡设计](levels.md)。

## 强化追逐者与章节

第11关开始逐个教学强化型，编号旁以“+”标识。冲锋者第一段冲空后调整300ms，若仍能对齐则重新完整预警一次；第二段冲空正常恢复。截击者在正式锁向前预告侧切400ms，执行时再次检查阻挡和占格，侧切后仍需完整观察及正式预警，冷却4秒。侦察者停下预告600ms，在当时玩家格落下持续2400ms的十字五格干扰场，场内暂停回充而不消耗已有电量，冷却5秒，每名最多一场，来源被击败后清除。正式锁向不因技能转弯；脉冲冻结敌人的能力预告，已落地干扰场按对局时间消退。

四章分别突出装配、供电、回收与控制区，使用墙面细节、地面标线和准备页短文建立区别，危险信息保持优先。

## 四章教学与挑战

1. **唤醒试验场（1—5）**：基本借墙、有限冲刺、闪避、截击预测、踏板和信标逐步出现。
2. **改变追逐路线（6—10）**：闸门与内墙、转角、双敌目标以及共享电量组合。
3. **分配注意力（11—15）**：双门选择、三敌压力、不同诱导条件与交叉预警。
4. **最后的试验（16—20）**：连续改变通路、分批诱导和资源安排；最终关用三间相连试验室串联三类敌人。

教学关允许简单解。中后期设计目标是多次独立设局与资源决策；是否达到目标以命令回放、简单策略专项记录和实际试玩分别验证，不以关卡数量或敌人数代替难度证据。

## 完整流程与存档

保留首页、继续挑战、四章选关、说明、设置、暂停、重试、下一关、星级、最终通关与自由重玩。对局优先显示地图、剩余敌人、电量与回充、信标寿命和门状态。危险提示先列正在冲刺者，再按蓄力剩余时间和编号排序；敌人与预警终点显示编号及类型符号，敌头上方显示蓄力倒计时，颜色不是唯一识别方式。

失败时记录致命敌人、接触类型、碰撞格和路线快照。可从结算进入冻结现场：红圈与叉标出碰撞格，金色框标出冲刺锁向时的完整通道或追踪接触来路；现场不推进规则，也不开放移动与技能。返回结算或重试，重试重新创建整局状态。

通关一星，时间达标一星，当关战术目标达标一星；战术为首次诱撞、信标诱撞、残骸接力、带回芯片、不同撞击位置或切门，每关只设一个，技能使用不扣星；无强制倒计时，信标次数不单独限制星级。每关最佳用时、最少闪避、最少信标和最高星级独立保存。继续挑战进入首个未完成关，全部完成后进入第 20 关；从第一关开始不会清空进度。

新版存档使用 `wallbait.save.v2`，并绑定 `foundry-v2` 关卡集。`collections` 按关记录已带出芯片及通关称号，新字段缺失视为空集合；已有 v2 解锁、收藏和设置保留。技能版成绩标记 `scoring: tactics-v1`；旧星级标“历史”且不计入新星级总数，重玩后在 `legacyStars` 封存旧星级并独立记录新成绩，旧快照用时不参与新规则最佳值比较。工具偏好经过枚举校验后保存，当前关未开放时回退闪避，不清除偏好。旧 `wallbait.save.v1` 原文保留且不覆盖，只继承静音和减少动态效果设置，显示旧版通关数量；旧成绩不解锁新版或参与新版评分。损坏或不可用存储回退到可游玩的内存状态，并提示保存失败。

## 操作与视觉

手机左手四向键，右手所选工具与信标，右上暂停；支持多点触控、松手和取消。电脑 WASD / 方向键移动，空格使用所选工具，E 放信标，Escape / P 暂停。

准备页把开始与返回入口保留在底部，装备和说明可滚动，区域与操作细节按需展开。首次地图绘制完成后才允许按钮或快捷键开局；重试就绪后自动开始，加载期间切后台则保留暂停。加载失败保持冻结，提供重新加载页面和返回选关。工具提示根据核心校验显示当前不可用原因，Tab 聚焦方向/技能按钮后可用 Enter 操作；修饰键组合不触发游戏快捷键。

深蓝试验场、青绿色阿零、橙红紫三类机械敌人；墙、门、踏板与危险通道以形状、字母、轮廓和纹理辅助颜色识别。首页与结算使用同主题矢量插画，对局用程序绘图，不依赖外部图片或字体。音效可静音，用户首次操作后解锁；减少动态效果关闭位置插值与震屏。实际验收状态见[验收文档](testing/README.md)。
