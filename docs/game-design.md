# 玩法设计：苹果与蛇

**撞墙了么** · **你追你的，墙就在那儿。**

操控红苹果，把三类蛇引向石墙、关闭的门或实心残骸，再横向脱身。四章20关，每关1—3条蛇，纯前端单人H5。用户指定的奶油底、粗描边、绿蛇红苹果画风取代机械试验场主题；参考图中的蓄力横幅和预告箭头不采用。

## 追逐与直冲

- 13×15整数格，规则固定步20ms；苹果每120ms走一格，首次按下立即走，松手停止。画面平滑和高清缩放不改变碰撞。
- 蛇没有蓄力状态、读条、停车锁定提示或提前展示的攻击路线。目标同行/列、五格内、视线畅通且满足短暂观察条件时，直接进入直冲。观察期间继续正常追踪，不是另一段停车蓄力。
- 冲出后保持方向和距离，不因玩家或信标改向。普通蛇每格100ms冲4格，截击蛇每格80ms冲3格，侦察蛇每格100ms冲5格；比旧版降低冲速。各关原启动延迟统一增加700ms，给开局观察时间。
- 追踪时绕墙；直冲撞墙、关门或实心残骸才淘汰，冲空后恢复再追。蛇头碰苹果即失败，蛇身无伤害，活蛇之间不碰撞。
- 移动、闪避、冲刺均逐格检查，不能穿墙、穿蛇头或交换位置。同一步先处理玩家，再统一处理蛇；命中优先判负，全部淘汰才获胜，胜负只触发一次。

| 类型   | 识别与目标                                 | 追踪每格 | 观察条件持续 | 直冲每格/距离 | 恢复   |
| ------ | ------------------------------------------ | -------- | ------------ | ------------- | ------ |
| 冲锋蛇 | 绿色圆头；追实际位置或信标                 | 300ms    | 120ms        | 100ms / 4格   | 800ms  |
| 截击蛇 | 黄色、闪电纹；预测苹果朝向前两格，遇墙截短 | 260ms    | 100ms        | 80ms / 3格    | 1000ms |
| 侦察蛇 | 紫色、圆纹；对玩家保持至少两格路径距离     | 360ms    | 240ms        | 100ms / 5格   | 600ms  |

侦察蛇对真人会拒绝撞障碍的直冲，信标能骗它冒进。信标存在时三类都直接追信标。三类除颜色外仍有符号与编号，单蛇普通关不重复显示编号标签。出生蛇身向后铺开，仅作表现，不能越过墙、门或角色。

强化蛇从第11关逐步出现：冲锋蛇冲空后调整300ms，再次对齐可直接追击；截击蛇侧切前预告400ms；侦察蛇预告600ms后留下2400ms十字干扰场，范围内暂停回充。后两者的能力落点提示用于说明额外技能，不是冲刺蓄力或锁定提示；能力执行后仍需满足直接冲刺的观察条件。

## 两个操作与共享电量

两格电，每3000ms恢复一格。闪避/脉冲/磁推三选一，固定信标从第5关启用；局内最多两个主动按钮，未开放的信标按钮隐藏。

- 闪避：立即前进两格，耗一电，无无敌；首格被挡不耗电，途中被挡停住。
- 信标：朝前投最多两格，遇障碍停在前一格，贴墙落脚下；持续2200ms，耗一电。不能重放仍在场的信标，已发动的冲刺不改向。
- 脉冲：第6关可选，暂停两格内无遮挡的蛇600ms；无目标不耗电，原攻击方向和剩余步时保留。
- 磁推：第9关可选，在无蛇直冲时推前方实心残骸一格；不可推到障碍、角色、信标、未取收藏或机关关键格。

三个工具与信标各耗一电，工具短锁240ms。同一步双技能先工具再信标，一电时工具成功就不放信标，工具无效则仍可放。共享回充进度、暂停和触控取消按原边界处理；详见[技能规格](design/skills.md)。

## 门、残骸与收藏

踩进字母踏板切换同字母门，站住或同组相邻踏板之间移动不反复触发。直冲期间冻结地形，切门请求待结束后执行；角色占门时不关门，可再次踩入取消待执行请求。

撞毁在最后蛇头格留一格残骸。空心叉框待生效、仍可走；所有直冲结束且格内无人后变实心，阻挡角色、视线、投掷与冲刺，可诱撞下一条蛇。新残骸覆盖信标时移除信标，不挤压角色。重开清空本局地形。

第7/11/18关各有可选收藏，普通移动或闪避经过拾取，通关后保存，失败或重开不保存本局携带。收藏与称号在选关页折叠档案中查看。四种称号保留：撞残骸、同一信标骗倒两蛇、零闪避通关，以及蛇冲到两格内时横向脱身并避过该次攻击。返回攻击路径会取消这次擦肩资格。

过关、时间达标、本关战术目标各一星，技能使用不扣星。20关主线、三条收藏路线、开放工具搭配与战术星重新生成正常操作回放；回放证明可解，不代表真人手感验收。第8/18/19关另有残骸接力证据，不再要求第11关复现旧版蓄力时序下同一中央格的复合路线。

## 界面与结束节奏

全局使用奶油底、深棕描边、浅绿棋盘、石墙、圆润蛇和红苹果，首页、选关、说明、准备、暂停、胜负、失败现场使用同一套视觉。原创SVG和程序绘图，高清画布最高3倍像素密度，无外部图片/字体依赖。

首页只留标题、宣传语与入口。准备页一句提示，后期装备短标签；星级条件、区域和详细操作折叠。对局常驻剩余敌人、时间、电量；门/信标/收藏等仅短状态，没有重复的教学段落。危险文字只描述已经发生的直冲或能力。桌面有一行按键提示，触屏隐藏。

规则结束立即冻结、清空输入、禁用方向与技能；胜利在此刻记成绩，防止停留阶段刷新丢进度。地图保留1200ms，撞击粒子可收尾但规则不再推进，再显示结算。切后台取消展示定时器，回前台重新留足1200ms；销毁或换关清理旧定时器。

结算默认只显示结果、星级/用时与下一步；详细成绩、收藏说明、换装备折叠，主操作固定在内容滚动区外。失败可查看冻结现场和建议，返回结算不重复记胜利。重试直接开新局。

电脑WASD/方向键、空格工具、E信标、P/Escape暂停；手机十字方向键与技能圆按钮，多点触控、滑动换向、取消释放。100dvh、安全区、窄屏和横屏布局，减少动态效果保留完整反馈。实际结果见[本轮记录](records/2026-11-04-cartoon-redesign.md)。
