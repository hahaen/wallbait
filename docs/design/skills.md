# 技能与追逐者升级规格

## 范围

- 四章20关、三类敌人、每关1—3名敌人；获胜仍靠诱撞墙、闸门或残骸。
- 信标固定槽，工具槽三选一，局内始终两个按钮。默认闪避；第6关起可选脉冲，第9关起可选磁推；在准备页选择、结算或暂停页可更换并重开，不在对局途中换技能。
- 脉冲：一格电，曼哈顿两格范围，直角路径至少一条无遮挡；暂停敌人600ms，恢复后原锁向与攻击路线继续。无目标不耗电，所有敌人阶段均可暂停；接触敌头仍失败。
- 磁推：一格电，面前实心残骸向前一格，预览共用规则；直冲期间不能推移，不排队。落点不能是墙、任何残骸、活敌头、信标、未收芯片、门或踏板。无合法落点不耗电。仍可能因规划不当堵路，可以重试。
- 共用两格电、3秒回一格，工具有240ms短锁；一帧双技能先工具后信标，电量不足时工具优先。

## 强化追逐者

强化型在原编号和类型符号旁标“+”，普通型继续承担基础教学。第11关引入强化冲锋蛇、第12关强化截击蛇、第14关强化侦察蛇，后续逐步组合。

- 冲锋蛇：第一段冲空后调整300ms；若仍有合法攻击轴线，则直接再次冲刺。第二段冲空后正常恢复；第一段撞墙立即淘汰，不增加血量。重新出手前可换目标，冲出后不转弯。
- 截击蛇：在直冲前，选择能对齐目标的邻格，预告400ms，再侧移一步；执行时落点被阻挡或有人则取消。冷却4秒；侧切后仍需满足对齐观察，再直接冲出。
- 侦察蛇：停下预告600ms，在当时玩家位置布置固定十字五格干扰场，持续2400ms；每名同时最多一场，冷却5秒。场内暂停回充、不扣已有电量、不限制移动和技能；击败来源敌人后场消失。仍能被信标诱骗。
- 暂停冻结所有阶段、控场、干扰与冷却；重试清空全部瞬态。脉冲冻结敌人自己的技能预告，已落地干扰场按对局时间消退。

## 关卡、奖励与视觉

- 1—5关基础教学、6—10关工具选择、11—15关逐个认识敌人绝招、16—20关组合。默认搭配全部可解；每关开放的替代搭配均须有正常命令通关回放；提供实际使用脉冲与磁推的通关样本。
- 过关、时间、当关战术目标各一星；不按工具使用次数扣星。战术目标为首次诱撞、信标诱撞、残骸接力、带回芯片、不同撞击位置或切门，逐关只设一个；不改变普通通关条件。
- 保留旧存档解锁、设置、芯片、称号和旧星级；旧星级标“历史”，不计入新战术星总数。重玩后保存新评分，并封存旧星级。工具选择校验后保存；早期关不可选工具时回退闪避，不清空偏好。
- 四章关卡沿用布局，全局统一卡通草地与石墙；不增加外部素材依赖。强化标识、侧切落点、干扰条纹、脉冲暂停与磁推落点均可识别，不显示提前锁定或冲刺预告路线。
