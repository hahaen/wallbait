# 项目体验与资源优化

以 `main` 的 `532ba98` 为起点，工作区和暂存区均干净，交付目标为 `origin/main`。

- 首页、说明、结算和对局改用同一张无损 WebP 图集。资源从 976,502 字节降到 658,064 字节，缩小 32.6%。从 Git 取出原 PNG 后逐字节比较解码结果，1254×1254 的 RGBA 像素完全一致。
- 无尽清波后，顶部把剩余蛇数换成一位小数的下波倒计时。显示值来自固定步波间计时，暂停随规则冻结，进场后恢复蛇数。
- 准备页通过「进入试验」或「开始挑战」开局，P 和 Escape 在准备期间保持原地。设置的音效和减少动态效果开关原位更新，读屏可获取开关状态，键盘焦点留在当前开关。保存失败时原位提示。

差异自审核对了图集尺寸、帧坐标和相对路径，波间暂停和下一波切换，准备页加载及快捷键，设置状态、焦点与存储失败。通过 `npm run check` 的 145 项规则、存档及回放测试、类型检查和生产构建。生产包在 `/wallbait/` 子路径通过图集加载和首关通关验证。

桌面 Chromium、手机尺寸 Chromium 与 WebKit 的相关流程共 67 项通过，2 项依赖 Chromium CDP 的多点触控用例在 WebKit 按配置跳过。在 WebKit 下另检查了 375×667 竖屏和 844×390 横屏。放大根字体并模拟减少动态效果时，两个设置开关和完成按钮仍完整可见，关闭弹窗会归还焦点。

按现有验收范围使用桌面和手机尺寸浏览器。Phaser 对局模块仍有约 1.22 MB，gzip 后约 338 kB，继续按需加载。本轮未部署，上线需重新构建并发布 H5 静态站点。
