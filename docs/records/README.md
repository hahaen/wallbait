# 开发记录

功能、修复和关键决策的实施记录保存在本目录。按实际开发建立文件，不提前生成空白记录。

文件名使用 `YYYY-MM-DD-主题.md`；同一天多个主题各自建文件。

每份记录包含：

- 目标与范围：要解决的问题、所属里程碑及相关模块文档。
- 实际改动：实现行为、涉及文件及重要选择的原因。
- 验证结果：执行的命令、结果，必要时链接到[详细验收记录](../testing/README.md)。
- 遗留事项：未完成、未验证的内容及后续工作。

规则或架构变化要同步修改对应整体文档，开发记录用于保留实施背景。
