# 无尽挑战：回环石园

起点为 `main` 的 `0e4924bd5175de1e76ff851e2e1ba8d633b07f5d`，工作区与暂存区干净，交付目标为 `origin/main`。

- 通过第5关后可从首页进入。39×45格地图整局连续使用；13×15格镜头随苹果平移、在地图边界停止。
- 首波单蛇热身，后续按当前苹果位置、通路和随机种子选出生点。清空一波后仍能移动、操作与回电；残骸可以跨波接力，过期后移除。地形变更会保留可通行路线。
- 被抓时按完成波数、撞毁数保存本地最佳；可用相同种子重试或另开一局。主线存档、地图和评分独立。
