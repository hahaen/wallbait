# 加载、准备页与操作反馈优化

起点：`main` / `f9c6d59ca4ecc6f21b83cea8dfc5cb3f0193e240`，跟踪 `origin/main`，工作区与暂存区干净。用户要求找出不合理之处并直接优化；保持四章 20 关、三类敌人和两个主动技能按钮，未改关卡、战斗参数或存档格式。

## 问题与处理

| 不合理之处                                                                          | 处理                                                                                                                                      |
| ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 资源仍在加载时就能点击进入或用 P / Esc 关闭准备页；加载错误也缺少恢复保护           | 每次开局先暂停，场景首次绘图后通过 `onReady` 解锁开始；失败保持暂停并提供页面重新加载。重试就绪后自动开始，加载中失焦或隐藏则等待手动继续 |
| 后期准备页堆叠教学、区域、芯片、战术星和三种装备，开始入口随长文滚出小屏            | 内容单独滚动，开始和返回固定保留；区域与操作细节可展开；前四关明确标注当前仅启用闪避                                                      |
| 面前有墙时闪避仍显示可用；磁推多种拒绝条件只提示“需空闲推移位”；干扰停充仍提示充电  | 闪避显示前方阻挡；脉冲提示近敌无遮挡；磁推区分攻击中、无残骸、落点占用和保留格；干扰时提示停充。磁推预览、原因与执行共用核心校验          |
| 原生方向/技能按钮只有指针处理，Tab 后 Enter 无动作；Ctrl / Command + P 也被截为暂停 | Enter 支持方向按住/松手和工具/信标单次请求；修饰键组合在暂停判断前排除                                                                    |

准备页在 375×667、根字号 125%、减少动态效果开启时，滚动装备区域后的[手机截图](../testing/evidence/optimization-prepare-mobile.png)保留底部两个入口。此截图用于布局验收，不代表实体手机测试。

## 评审与验证

本轮按修改 → 差异自审 → 验证执行，未委派子代理或进行外部人工评审。检查了纯规则边界、磁推拒绝与执行的一致性、初始暂停、异步返回状态引用、加载中离开、后台取消自动开始、焦点和输入清理；自审无遗留问题。

- `npm run check`：129 项 Vitest、ESLint、Prettier、严格类型检查和生产构建通过。包含 20 关主线、芯片/替代装备/战术回放及 140 轮固定策略；关卡与命令夹具未重写。
- 新增浏览器专项：15/15 通过，覆盖桌面 Chromium、手机尺寸 Chromium 与 WebKit。实际拦截模块请求，验证加载前禁止开始、失败冻结与重新加载恢复、离开后迟到资源不复活旧场景；320×568、375×667、844×390、768×1024 下检查底部入口、装备焦点滚动与无横向溢出；Enter 通过原生键盘完成第一关侧撤通关。
- 首次专项失败源于 Vite 为热更新模块附带查询参数，拦截表达式未匹配；修正测试匹配并重新自审后，15 项完整复验通过。未将失败运行记作通过。
- 原有浏览器完整回归：62 项通过、4 项按既有配置跳过，包含原生键盘连续 20 关、最终结算、自由重玩与刷新恢复，三端的芯片、装备、强化预告、失败现场、暂停、输入与残骸接力。加上新增专项，本轮浏览器合计 77 项通过、4 项跳过。跳过项为手机两端的桌面连续闯关，以及 WebKit 的两项 Chromium CDP 测试。
- 已构建产物的 `/wallbait/` 子路径验收：1/1 通过，脚本资源加载、实际通关和存档恢复正常。文档 149 个本地链接检查通过。

旧浏览器测试自动覆盖的六张历史截图已恢复，新增准备页截图独立命名保存，保留历史证据与当前证据的区别。

Phaser 按需包仍有超过 500kB 的构建提示，首页不等待该包；未为消除提示引入新依赖。浏览器模拟与命令回放不代表真机触感、不同熟练度真人难度或低端实体设备性能；这些项目继续见[后续事项](../remaining-work.md)。

## Git 与发布范围

必要验证通过后已备份文件、差异与索引，获取远端 `main` 确认无额外更新，无需合并；仅提交本轮代码、测试、文档和独立截图。提交使用 `fix(ui): 完善开局加载与准备页操作反馈`，推送目标为 `origin/main`；最终提交哈希及本地/远端一致性在交付说明中核对。远端 CI 状态未查询，不将本机通过写作远端通过。

本轮**未部署或公开发布**。运行时代码与样式有变，上线需要重新构建并发布 H5 静态站点。
