# 全向走位与不规则石墙

起点为 `main` 的 `5255993eb5ebcdccc1e03d7143584be56064025f`，工作区与暂存区干净，交付目标为 `origin/main`。

- 手机摇杆保留拖动角度，电脑按住两个垂直方向键可斜走。普通移动按输入斜率组合直步和斜步，画面沿已判定的路线滑动。工具沿主轴朝向，蛇仍沿格追踪和直冲。
- 第1、7、14关分别在教学石块、L形墙和中央石岛使用斜边与不规则轮廓。形状覆盖的格心构成墙格，普通斜步另外检查轮廓线。遇到方墙、关闭的闸门或实心残骸时沿可通过的一侧移动。
- 保留三个关卡的原墙格。首轮策略复验发现第7关的 L 形墙端少覆盖一格，补齐后重新评审、复验。

差异自审覆盖输入释放、暂停、角落碰撞、工具朝向和渲染对齐。`npm run check`通过，含139项测试、20关回放和生产构建。桌面 Chromium、手机尺寸 Chromium 和 WebKit 的相关回归48项通过、3项跳过；调整石墙亮边与摇杆标记后复验14项通过、1项跳过。跳过项是 Chromium 专属多点触控用例。生产包子路径验收通过。

第1关用浏览器触摸事件实际拖动摇杆，通过画布中苹果的位置核对斜向过渡和松手停止。第7、14关分别核对横屏和375px竖屏的石墙、摇杆和技能区，使用存档夹具选关。验证限于浏览器。

本轮未部署。上线需重新构建并发布H5静态站点。
