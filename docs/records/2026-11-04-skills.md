# 双方技能与战术星

起点 main / cb59f1420f405bf1daaa0e5efaa0188e23564f52，跟踪 origin/main；工作区和暂存区干净。用户授权完整实施、评审验证后提交推送，先不部署。

## 实现

- 信标固定槽，工具槽在闪避、脉冲、磁推中选择；第6/9关依次开放新工具，准备页选择，暂停/结算可更换并重开。局内仍两个按钮，空格使用所选工具，E投信标。
- 脉冲暂停两格内无遮挡敌人600ms，固定施放原点，保留已锁定路径；磁推在攻击间隙推移面前实心残骸，执行与落点预览共用校验。无有效目标不耗电，所有工具共用两格电及240ms短锁。
- 三类强化敌人逐步引入连冲、侧切、干扰，保持完整正式预警与明确反制。第11/12/14关分别教学；后续关逐渐组合，每关仍1—3名敌人。
- 20关配置独立战术星，技能使用不扣星；保留芯片与称号。四章增加区域短文、墙面高光和地面标线，增加技能音效与状态提示。
- 旧解锁、设置、收藏和旧星级保留；历史星级单独标注，重玩后封存旧星级并独立记录新评分，旧用时不参与新成绩比较。工具偏好校验并保存，当前关未开放时回退默认工具。

完整规则、时序及兼容边界见[技能规格](../design/skills.md)、[玩法设计](../game-design.md)与[逐关回放](../levels.md)。

## 评审

使用 code-review 的 Standards / Spec 两轴独立只读代理评审，先评审后验证。首轮修复脉冲波纹跟随阿零、危险顺序未计暂停时间两项反馈问题，补齐章节短文、通用碰撞提示与双技能优先级文档；复核两轴均无遗留。

最终截图QA发现原侧切预告测试也能匹配教学文案，已收紧为敌人编号、类型和实时能力提示。两轴复核确认首次预告与重开后暂停都要求真实技能状态；只改测试匹配，没有修改游戏规则。随后6个受影响用例独立复验通过。

## 实际验证

- `npm run check` 最终通过：ESLint、Prettier、13个Vitest文件/127项测试、严格类型检查与生产构建。Phaser原有引擎大包提示仍在，构建成功。
- 重新生成并正常重放20关主线、3条芯片支线、27条替代工具搭配及20条战术目标回放；第6关脉冲、第11关磁推样本要求实际成功使用工具后通关。回放只发正常命令，不写游戏坐标、敌人或胜负。
- 7种固定算法×20关重新计算并默认重算通过，算法和门槛未放宽；原地等待0胜，仍只有第1/3/7关有记录中的简单解。此表采用默认闪避，替代搭配另由技能回放覆盖，不宣称穷尽所有套路。
- 新技能初轮9项浏览器专项通过；补充原生手机 `tap()` 与强化预告后，独立15项专项通过。
- 完整命令 `npm run test:e2e -- --output=test-results/skills-final --reporter=list --workers=2 --max-failures=1` 通过：**62项通过、4项按配置跳过**，总墙上时间10.8分钟。桌面原生键盘连续20关旅程6.3分钟，含最终通关、自由重玩与刷新恢复；其余包含手机尺寸Chromium/WebKit、触控、取消与多指、存档、失败现场、重开、芯片与新工具。
- 跳过项为手机/WebKit重复的桌面连续旅程2项，以及WebKit不支持的Chromium CDP专项2项，不能记为通过。
- 收紧预告断言后再次通过check，并运行 `npx playwright test tests/e2e/skills.spec.ts --grep '强化能力' --output=test-results/skills-warning-final --reporter=list --workers=2 --max-failures=1`：桌面/手机Chromium/WebKit共**6项通过**，1.6分钟。游戏代码与完整回归时一致，仅强化了测试断言。
- `npm run test:static -- --output=test-results/skills-static --reporter=list`：**1/1通过**，生产包在 `/wallbait/` 加载资源、通关并恢复进度。
- 375×667、320×568、844×390准备页无横向溢出，长面板可滚动到装备与开始按钮。手机尺寸战斗中地图与操作区不重叠，工具仍两个按钮；已查看本轮截图。

初次完整浏览器验证中断：轨迹明确记录Vite连接丢失、重连后页面返回首页，另有执行环境长时间中断；该轮不计为通过。固定独立测试服务并在测试期间临时保持机器运行后重跑，得到上述完整结果，没有修改规则回避失败。不同浏览器命令均使用独立trace输出目录；测试覆盖的历史截图已按运行前备份恢复。

## 限制与交付范围

本轮未进行iPhone Safari / Android Chrome实体设备触感、不同熟练度真人难度、低端实体性能或主观音效验收。自动回放只证明存在合法解，不能保证每种击杀顺序或磁推布局都能通关；不当造墙仍可能需要重试。实际人类难度应在真实试玩后校准。

交付目标保持原始工作区main→origin/main。必要验证通过后按仓库规范备份、同步并提交推送；实际提交哈希、远端及工作区核对结果由本轮交付回复报告。本机结果不推断远端CI结果。

本轮改变游戏产物，**上线需要重新构建并发布H5静态站点**。本次不部署、不公开发布。没有后端、原生客户端或小程序。
