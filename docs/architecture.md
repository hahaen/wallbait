# 架构设计

Phaser 3 + TypeScript 严格模式 + Vite。纯前端，无 UI 框架、物理引擎、通用 ECS 或后端。

## 边界

- `src/core/types.ts`：整数坐标、关卡、输入命令、状态与一次性事件。
- `src/core/config.ts`：毫秒时间、三类蛇基础参数。
- `src/core/engine.ts`：初始化、20ms 固定步、BFS 追踪、锁向冲刺、逐格碰撞、暂停与星级。无 Phaser、DOM、存储依赖。
- `src/core/levels.ts`：20 关数据及配置合法性检查。
- `src/game/`：Phaser 组装、规则驱动、绘制、插值与反馈。
- `src/input/`：键盘和多指 Pointer Events 转成命令，不直接写坐标。
- `src/ui/`：首页、选关、HUD、操作区与覆盖面板，负责发出操作。
- `src/storage/`：版本化存档，边界读写、校验与异常回退。

## 时间与碰撞

`step(state, command)` 只推进 20ms。画面累加帧间隔，限制补算，暂停清空累积时间与输入。动画不决定规则。普通移动与蛇头表现采用独立插值，逻辑位置始终为整数。闪避无无敌，逐格检测当前蛇头，因此不能与蛇头换位穿越。

一步处理：清空旧事件 → 冻结状态检查 → 时间和冷却 → 苹果逐格位移 → 每条蛇状态机与逐格位移 → 头部触及优先判负 → 全部淘汰判胜。追踪选择 BFS 距离递减的可通行格；障碍阻断蓄力视线。蛇之间与蛇身不参与碰撞。状态终结后不再推进或重复发事件。

## 验证与构建

Vitest 验证规则与存档；20 关使用保存的纯命令回放，从正常出生执行到胜利，搜索器仅在显式生成回放时运行。Playwright 验证浏览器流程与触控，不冒充真机。Node.js 24.x，锁文件安装；静态资源相对路径，未来支持 `/wallbait/`，无 history 路由。CI 只检查，不发布。
