# 架构设计

Phaser 3、严格TypeScript和Vite。纯前端，不引入框架、后端或通用ECS。

- `core/`：整数格、20ms固定步、纯状态机与波次。没有Phaser、DOM或存储依赖。
- `input/`：键盘/多点Pointer Events转换命令，不直接改角色坐标。
- `game/`：场景、程序绘图、插值、音效。最高3倍物理像素画布，摄像机缩放保持416×480逻辑坐标。
- `ui/`：首页、准备、HUD、暂停、结算、失败现场与展示计时器。
- `storage/`：存档校验、兼容、设置与无尽纪录。

## 时间与状态

`step(state, command)`只推进20ms。处理顺序为时间/回充/信标 → 可生效地形 → 工具 → 投信标 → 普通移动 → 蛇状态与逐格冲刺 → 命中优先判负 → 地形生效。无尽场景由 `stepEndless` 调用该步骤并在清空后计时换波。同格、换位、闪避中间格均按整数格检查；暂停和终局不再推进规则。

蛇从`tracking`直接进入`dashing`，没有`charging`。`aimMs`仅要求同轴观察条件连续成立，期间仍追踪移动；`beginDash`固定方向、剩余步数与完整`attackPath`，一次发出`dash`事件。旧字段`charges`保留为攻击次数，供首次诱撞战术统计；不代表蓄力。`warningPath`仅计算内部剩余可经过格与失败快照，当前对局不显示预告路线。

追踪共用BFS和实际地形。`solid`只含静态墙，`blocked`另含关门和实心残骸。直冲时冻结门/残骸，结束后安全应用，角色占格不夹伤。信标落点、脉冲目标与磁推预览共用核心规则。强化蛇侧切/干扰保留独立阶段与能力落点反馈，不新增冲刺蓄力。

不规则静态墙由格边坐标的多边形定义。关卡初始化用同一轮廓生成整数墙格，斜步还检查格心连线与轮廓的相交情况，渲染直接绘制该轮廓。苹果沿已判定的步进线段平滑移动。

## 展示与持久化

初始地图绘制后才允许开始，资源失败保持冻结。暂停、失焦、切后台清空输入并暂停规则；恢复清空帧余量。终止帧对齐真实格，终局仍允许粒子收尾。

UI 收到被抓事件后禁用操作并立即保存新纪录。结算弹窗延后 1200ms，后台取消定时器，回来重新停留，离场或重开清理旧定时器。

存档使用 `wallbait.save.v3`，继承有效旧档的无尽纪录与偏好，保留原始旧键。异常时游戏使用内存状态。
